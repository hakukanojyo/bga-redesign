# 狀態檢查清單

> 改寫自 ux-skills 的 `grill-flow` 問題庫，例子換成這個專案的畫面。

開功能 issue 填「要交付的狀態」之前，以及對照功能清單、PRD、Figma 找缺漏時，照這份逐項問。不用每題都問：只看這個功能會遇到的。

每題的答案要有**來源**（Figma 節點、PRD 段落、功能清單編號）。找不到來源的，記下來問設計，不要自己決定。

## A. 目標和入口

| 問題 | 追問 |
| --- | --- |
| 使用者來這裡要完成什麼？做完看到什麼畫面？ | 只能留一個畫面的話，留哪個？ |
| 從哪裡進來？首頁、搜尋、側欄、直接貼網址？ | 直接貼網址進來，看到什麼？ |
| 第一次來和第十次來，看到的一樣嗎？ | 資料存在哪？清掉瀏覽器會怎樣？（例：收藏、裝置建議橫幅 FB-06 的「記住關閉」） |

## B. 等資料的狀態（每個要等資料的步驟都問）

| 問題 | 追問 |
| --- | --- |
| 按下去之後，0.1 秒、1 秒、10 秒各看到什麼？ | 回應只要 80 毫秒時，骨架一閃而過反而更糟，要不要延遲顯示？ |
| 資料回來是空的？ | 第一次使用、搜尋無結果（SRCH-06）、被篩選光了（FILT-11），三種空的文案一樣嗎？ |
| 失敗了？有幾種失敗？ | 連不上、伺服器錯、找不到。使用者下一步能做什麼？剛選的條件還在嗎？ |
| 等很久都沒回來？ | 多久算太久？誰決定的？ |
| 列表成功但圖片失敗？ | 整頁錯誤還是只有那一格？ |
| 網路斷了？ | 連線錯誤頁（FB-07）什麼時候出現？斷線時按按鈕會怎樣？ |
| 使用者連點兩次？ | 「加入此遊戲桌」按第二次時按鈕長什麼樣？（TABLE-13 加入中） |
| 先顯示成功、背景再處理？ | 取消收藏（FAV-05）先移除再顯示「復原」，失敗時怎麼倒回去？ |
| 兩個請求回來的順序顛倒？ | 搜尋輸入「卡」再輸入「卡坦」，畫面最後顯示哪個結果？ |
| 資料在背景自動更新？ | 開放桌每 10 秒刷新（TABLE-06），使用者正要按加入時那一列跳走了？已額滿（TABLE-14）的列什麼時候消失？ |
| 兩個人同時搶同一個位置？ | 加入失敗（TABLE-08）時，那一列要不要馬上改成已額滿？ |
| 回到這一頁，資料要重新抓嗎？ | 這份資料「新」有多重要？開放桌和遊戲介紹的答案不一樣 |

## C. 網址和換頁

| 問題 | 追問 |
| --- | --- |
| 按上一頁、重新整理、下一頁？ | 篩選條件和排序在網址裡嗎？重新整理後還在嗎？ |
| 頁面不存在？ | 404 頁能帶使用者回到哪裡？ |
| 側欄、Bottom Sheet、彈窗開著時按上一頁？ | 是關掉面板，還是離開這一頁？ |
| 換頁之後，鍵盤和螢幕閱讀器使用者怎麼知道？ | 焦點在哪？捲動位置有沒有回到頂端？分頁標題有沒有變？ |
| 外部連結怎麼開？ | 規則 PDF、影音教學（GAME-08、09）開新分頁嗎？ |

## D. 一致性

| 問題 | 追問 |
| --- | --- |
| 全站的載入中、空的、錯誤長得一樣嗎？ | 第 12 個畫面的錯誤要重做嗎，還是用共用元件？ |
| 同一份資料出現在兩個地方？ | 在遊戲頁加入收藏，右側欄的收藏列表什麼時候更新？ |
| 同一件事在不同地方叫一樣的名字嗎？ | 牌桌、遊戲桌、對局，是同一個東西嗎？ |

## E. 無障礙

| 問題 | 追問 |
| --- | --- |
| 只用鍵盤能完成整個流程嗎？ | 確認彈窗（MYTBL-08）關掉後，焦點回到哪？ |
| 「載入中」「加入失敗」怎麼被聽見？ | 螢幕閱讀器使用者按下加入後聽到什麼？ |
| 對比、字級、點擊範圍夠嗎？ | 停用、懸停、錯誤狀態的對比也檢查過嗎？平板的觸控尺寸（SYS-05）？ |
| 只靠顏色表達狀態？ | 「你的回合！」（MYTBL-04）只靠外框顏色嗎？ |
| 有動畫嗎？ | 減少動態效果（SYS-08）開著時還看得懂嗎？ |
| 觸控裝置沒有懸停？ | 懸停才出現的按鈕（HOME-07）在平板上怎麼按到？（SYS-04） |

## F. 效能感受

| 問題 | 追問 |
| --- | --- |
| 第一屏最大的東西是什麼？ | 主視覺圖片載入前，版面會跳動嗎？ |
| 骨架的尺寸和真的內容一樣嗎？ | 內容出現時，按鈕會不會被擠走，害使用者按錯？ |
| 中文字型要載入多大？ | 字型還沒到的時候畫面長怎樣？ |
| 背景模糊在舊電腦上順嗎？ | 低效能時的降級（SYS-10）怎麼觸發？ |

## G. 安全

| 問題 | 追問 |
| --- | --- |
| 使用者輸入的文字會原樣顯示嗎？ | 搜尋框貼一段 `<script>` 會怎樣？（不用 `v-html` 顯示使用者輸入） |
| 需要金鑰嗎？ | `VITE_` 開頭的變數會被打包進網站，所有人都看得到 |

## H. 展示和範圍

| 問題 | 追問 |
| --- | --- |
| 展示時怎麼讓人看到載入中和失敗？ | 用 `?scenario=slow`、`error`、`empty` 切換（ADR 0005） |
| 這個功能哪些可以假、哪些必須真？ | 被砍掉的部分，展示時怎麼說？ |
| 寬度小於 768 的手機打開？ | 縮放顯示平板版、頂部橫幅（SYS-02、FB-06）有出現嗎？ |

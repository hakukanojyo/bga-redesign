# 0016. 提示（Toast）改到畫面上方

- 狀態：已採用
- 日期：2026-11-05

## 背景

[0015](0015-sonner-toast.md) 把提示放在畫面下方置中（平板在底部導覽列上方）。實際操作時發現提示在下方很容易漏看：桌面使用者的視線在畫面上半部，平板的提示又和底部導覽列擠在一起。Apple HIG 的版面原則也建議重要的資訊照閱讀順序放在上方。

## 決定

- `<Toaster>` 改成 `position="top-center"`，離畫面上緣 `Header 高度＋16`（`calc(var(--header-height) + 16px)`），桌面和平板一樣
- 用 `--header-height` 算，Header 改高度時提示跟著移，不用另外改
- 其他規則（樣式、停留時間、疊放、一個提示最多一個動作）不變，照 0015

## 考慮過的選項

- **維持下方**：Material Design 的 Snackbar 放下方，離拇指近、不擋內容；但這個網站以桌面為主，平板下方又有導覽列，提示容易被忽略
- **右上角**：常見於後台、桌面應用，但平板寬度不夠時會擋到 Header 右邊的頭像

## 代價

- 提示會暫時蓋住 Header 下方的內容，例如平板遊戲頁吸頂的按鈕列。提示 3～5 秒就消失，滑鼠移上去才會暫停
- PRD 7.6 第 5 條、產品規則、Figma 的提示畫板要一起改成上方

# 0004. shadcn-vue 只用在行為複雜的元件

- 狀態：已採用
- 日期：2026-11-03

## 背景

確認彈窗、下拉選單、提示、Bottom Sheet 有很多看不到的行為：焦點要鎖在彈窗裡、Esc 關閉、關掉後焦點回到原本的按鈕、螢幕閱讀器要讀得到。自己寫容易漏。其他元件（卡片、按鈕、列表）主要是長相，照 Figma 寫比較快。

## 決定

元件只有兩種：

- **shadcn-vue**（底層 Reka UI）：Modal、Select、Toast、Bottom Sheet。樣式改成設計稿的樣子
- **自己寫的**：其他元件照 Figma 寫

## 考慮過的選項

- **全部用 shadcn-vue**：元件多、可以直接用，但每個都要改樣式，而且很多元件設計稿沒有用到
- **全部自己寫**：最貼近設計稿，但無障礙行為容易漏
- **Vuetify、Element Plus**：自帶 Material 或自己的設計語言，改成設計稿的樣子很費工

## 代價

shadcn-vue 會把元件原始碼複製進專案，之後升級要自己合併改動。只用在少數元件，影響範圍小。

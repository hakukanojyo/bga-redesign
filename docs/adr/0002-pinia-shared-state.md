# 0002. 跨頁面的資料放 Pinia

- 狀態：已採用
- 日期：2026-11-03

## 背景

收藏、我的牌桌、篩選條件會在很多頁面和側欄同時用到。例如在遊戲頁按收藏，右側欄的收藏列表要馬上更新。

## 決定

跨頁面共用的資料放 Pinia（`src/stores/`），一種資料一個 store。只有一個元件用的狀態（下拉選單開或關）留在元件裡。

## 考慮過的選項

- **自己寫共用的 `ref`**（模組裡放一個 `ref`，各頁 import）：小專案夠用，但資料一多，每種各自寫一套存取、存到瀏覽器的方法，寫法會不一致、難除錯
- **props 一路往下傳**：側欄和頁面不是上下層關係，傳不到

## 代價

多一個要學的工具。Pinia 是 Vue 官方推薦的，Vue Devtools 可以直接看到每個 store 的值和是誰改的。
